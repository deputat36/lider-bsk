# Ассеты бренда РА «Лидер»

Этот каталог — единый источник фирменных digital-ассетов проекта.

## Канонические файлы

### `logo-lider-header.svg`

Статус: основной горизонтальный digital master.

Использование:

- шапка сайта;
- документы;
- презентации;
- коммерческие предложения;
- макеты, где полный логотип читается уверенно.

Не заменять текстовой надписью «ЛИДЕР» и не перерисовывать CSS-фигурами.

### `logo-lider-mark.svg`

Статус: отдельный векторный фирменный знак.

Использование:

- avatar;
- favicon/app icon source;
- маленькие digital-носители;
- маркер бренда;
- компактные места, где полный lockup не читается.

Перед изготовлением плоттерной/одноцветной версии требуется убрать градиент в производственном файле и проверить результат в масштабе.

### `leader-tokens.css`

Статус: digital source of truth для цветов, нейтралей, радиусов, теней, типографических токенов, spacing и motion.

Основной orange: `#FF6A00`.

### `leader-icons.svg`

Статус: системный sprite line-icons для собственных интерфейсов РА «Лидер».

Не использовать его вместо официальных логотипов сторонних платформ.

### `leader-components-v1.css`

Статус: базовый presentation-layer для общих digital-компонентов.

## Legacy/reference

### `logo-lider-light.svg`

Статус: reference only.

Файл содержит встроенный raster image внутри SVG-контейнера. Его нельзя считать чистым векторным master для крупноформатной печати, плоттера, гравировки или изготовления объёмных элементов.

### `source/logo-lider-original-20260621.svg`

Статус: исторический исходный материал/reference.

Не редактировать как рабочий production master без отдельной задачи.

## Производственные правила

Для печати, плоттера, трафарета, гравировки, фрезеровки и объёмных букв итоговый файл должен проверяться под конкретную технологию.

Обязательно проверить:

- отсутствие embedded raster там, где нужен вектор;
- отсутствие неподдерживаемых эффектов;
- плоский spot/solid color при одноцветном производстве;
- замкнутость контуров при необходимости;
- минимальные мосты/зазоры;
- читаемость дескриптора;
- фактический цвет плёнки/краски по физическому образцу.

## Правило для тёмного фона

Пока в каталоге нет отдельно визуально подтверждённого чистого vector white/orange full lockup, `logo-lider-header.svg` на тёмном или сложном фоне размещается на светлой защитной плашке. Нельзя автоматически перекрашивать master и считать результат утверждённым логотипом.

Отдельный знак допускается без плашки, если его контраст и форма сохраняются.

## Изменение ассетов

Изменение геометрии логотипа, Brand Orange или master-файла — изменение бренд-системы. Оно должно идти отдельным PR с визуальной проверкой и обновлением `docs/BRAND_SYSTEM_RA_LIDER.md`.
