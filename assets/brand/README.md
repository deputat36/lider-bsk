## Канонические файлы

### `logo-lider-header.svg`

Статус: основной digital-файл с исходным изображением владельца от 17.07.2026. Компоновка вертикальная, размеры шапки 108×98.4 px (mobile 82×74.7 px). Это встроенный raster image в SVG, не печатный векторный master.

Использование:

- шапка сайта;
- документы;
- презентации;
- коммерческие предложения;
- макеты, где полный логотип читается уверенно.

Не заменять текстовой надписью «ЛИДЕР» и не перерисовывать CSS-фигурами.

### `logo-lider-mark.svg`

Статус: тот же исходный растр с viewport только на знак. Геометрия не перерисована.

Использование:

- avatar;
- favicon/app icon source;
- маленькие digital-носители;
- маркер бренда;
- компактные места, где полный lockup не читается.

Для плоттера и большой печати нужен подлинный векторный исходник владельца; текущий digital-растр не подходит.

### `leader-tokens.css`

Статус: runtime source of truth для цветов, нейтралей, радиусов, теней, типографических токенов, spacing и motion на сайте/в CRM.

Основной orange: `#FF6A00`.

### `leader-tokens.json`

Статус: переносимая копия ключевых design tokens для дизайн-инструментов, документации и non-CSS clients.

JSON не должен расходиться с CSS по Brand Orange, Graphite, Manrope, базовым радиусам, container и spacing scale.

### `leader-icons.svg`

Статус: системный sprite line-icons для собственных интерфейсов РА «Лидер».

Не использовать его вместо официальных логотипов сторонних платформ.

### `leader-components-v1.css`

Статус: базовый presentation-layer для общих digital-компонентов.

### `leader-motif-rise.svg`

Статус: канонический широкий фоновый мотив для публичного сайта.

Использование:

- dark hero;
- CTA-секции;
- крупные графитовые промоблоки;
- редкий декоративный фон без смысловой нагрузки.

Правила:

- размещать как декоративный слой с `aria-hidden="true"` или через CSS background;
- не использовать как логотип;
- не растягивать непропорционально;
- не повторять много раз по странице;
- не накладывать поверх важного текста;
- не добавлять к нему случайные glow/neon-эффекты.

### `leader-motif-corner.svg`

Статус: канонический компактный угловой мотив.

Использование:

- угол крупной секции;
- редкий акцент в CTA;
- карточка/панель, которой нужен фирменный маркер;
- декоративный край изображения.

Не использовать на каждой карточке. Это акцент, а не обязательная рамка интерфейса.

### `source/logo-lider-original-20260621.svg`

## Производственные правила

Для печати, плоттера, трафарета, гравировки, фрезеровки и объёмных букв итоговый файл должен проверяться под конкретную технологию.

Обязательно проверить:

- отсутствие embedded raster там, где нужен вектор;
- отсутствие неподдерживаемых эффектов;
- плоский spot/solid color при одноцветном производстве;
- замкнутость контуров при необходимости;
- минимальные мосты/зазоры;
- читаемость дескриптора;
- фактический цвет плёнки/краски по физическому образцу.

## Правило для тёмного фона

Пока в каталоге нет отдельно визуально подтверждённого чистого vector white/orange full lockup, `logo-lider-header.svg` на тёмном или сложном фоне размещается на светлой защитной плашке. Нельзя автоматически перекрашивать master и считать результат утверждённым логотипом.

Отдельный знак допускается без плашки, если его контраст и форма сохраняются.

## Изменение ассетов

Изменение геометрии логотипа, Brand Orange или master-файла — изменение бренд-системы. Оно должно идти отдельным PR с визуальной проверкой и обновлением `docs/BRAND_SYSTEM_RA_LIDER.md`.
