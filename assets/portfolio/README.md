# Материалы работ

Публичная выборка управляется `docs/PUBLIC_PORTFOLIO_MANIFEST_V1.json`.
В карточку попадают только записи `publish: true` с существующим изображением,
размерами, просмотренным alt и названием исходного файла.

Добавлено 10.10.2026 из ранее переданных владельцем материалов:

- `1000003569.jpg`: фотография объёмных букв «ЦВЕТЫ» на рабочем столе.
  Файл скопирован без изменения изображения. Указан этап производства;
  точный заказчик, адрес, дата, материалы, подсветка и результат установки
  из фотографии не выводятся.
- `наклейка бормаш пески 125 на 32.png`: графический макет с обозначением
  «БОРМАШ». Веб-версия — lossless WebP с теми же размерами и проверенным
  совпадением RGBA pixels. Публичная подпись указывает 2D-макет, не фотографию.

Эти материалы не доказывают портфолио 3D-рендеров или готовых роликов.
Остальные прежние записи остаются `awaiting_originals` до доступа к соответствующим
фотографиям. Их названия и описание сами по себе не являются готовым кейсом.
