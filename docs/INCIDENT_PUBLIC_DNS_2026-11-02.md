1. Открыть https://cp.beget.com/, выполнить secure browserAuth при необходимости.
   Проверить домен lider-bsk.ru, регистрацию/делегирование и журнал изменений.
2. Сохранить полный текст действующей DNS-зоны и NS до изменений. В домене
   используется VK WorkSpace: реальные MX/TXT/SPF/DKIM/verification брать из
   текущей зоны/кабинета, не заменять прежними значениями Beget из старых чатов.
3. Если сохраняется отказ DNS-инфраструктуры Beget, требуется восстановление
   обслуживания у провайдера. Переход на другие NS допустим только после
   переноса и проверки полной зоны и при наличии доступа к делегации.
   Не нажимать «Восстановить записи по умолчанию» и не менять NS вслепую.
4. При подтверждённой ошибке записей исправить только относящиеся к сайту:
