# CSS страницы цен

Дата: 2026-07-13.

Контур: публичная страница `prices.html`.

## Цель

Перенести большой встроенный CSS-блок страницы цен в кешируемый asset без изменения клиентских ориентиров, таблицы расчёта, CTA, SEO, structured data и формы заявки.

## Итоговая схема

- общие стили формы: `assets/public-lead-form.css?v=14`;
- стили страницы цен: `assets/public-prices.css?v=1`;
- логика формы: `assets/public-lead-form.js?v=14`.

Специфичные стили страницы загружаются после общих стилей формы.

## Защищаемые элементы

Проверка сохраняет:

- H1 «Цены и ориентиры на рекламу»;
- карточки направлений и service-prefill;
- таблицу данных для расчёта;
- четыре шага подготовки заявки;
- CTA и контейнер формы;
- мобильный breakpoint 900 пикселей.

## Автоматизация

- `tools/check_public_prices_css.py`;
- `.github/workflows/public-prices-css-check.yml`.

При ошибке workflow сохраняет artifact `public-prices-css-report`.

## Границы

Миграция:

- не изменяет цены-ориентиры, тексты, ссылки или форму;
- не добавляет внешние CSS-ресурсы;
- не затрагивает CRM, `nav_*` или `nav_v2_*`;
- не меняет Supabase schema, RLS, Auth, Edge Functions или production data.
