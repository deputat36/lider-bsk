## История разрешения публикации

До разрешения изменения были закоммичены только локально в
`agent/recover-crm-work-20261022`.
Автоматическая approval-проверка отклонила `git push`: публикация исходного
кода CRM и восстановленных schema artifacts в GitHub требует явного разрешения
владельца. Через другой инструмент отправка не выполнялась. Read-only
`git ls-remote` тогда подтвердил отсутствие этой ветки на сервере; PR, CI и Pages
на тот момент ещё не запускались.

22.10.2026 владелец явно разрешил отправку подготовленной ветки в публичный
`deputat36/lider-bsk` и создание PR: «Разрешаю. Продолжай работу». Доставка
выполнена от этого разрешения, PR #591/#592 объединены и опубликованы;
повторное согласование GitHub не требуется. Отдельное ограничение на изменения
production Supabase сохраняется. Итоговые CI и публикация зафиксированы выше и в PR.

Первоначальная GET-only проверка восьми публичных файлов дала 8/8 HTTP 200: главная,
