# Публичная страница 404

Дата: 2026-07-13.

Контур: публичный сайт РА «Лидер».

## Проблема

В репозитории отсутствовал `404.html`. На GitHub Pages пользователь, открывший старую или ошибочную ссылку, получал стандартную техническую страницу без фирменного оформления и понятного возврата к услугам.

## Решение

Добавлен `404.html` в чёрно-оранжевом стиле РА «Лидер».

Страница:

- объясняет ошибку обычным клиентским языком;
- содержит телефон агентства;
- возвращает на главную;
- ведёт к общей странице заявки;
- предлагает услуги, примеры задач, цены и контакты;
- содержит ссылку на политику обработки данных;
- адаптирована для мобильных экранов;
- не загружает внешние библиотеки;
- не подключает форму и не создаёт обращения.

## SEO

Страница имеет:

- title;
- description;
- один H1;
- `noindex, nofollow`;
- отсутствие canonical.

`404.html` не добавляется в sitemap.

## Доступность

- используется один `main`;
- блок полезных маршрутов оформлен как `nav` с `aria-label`;
- декоративный код 404 скрыт от экранных дикторов;
- ссылки и кнопки имеют читаемые текстовые подписи;
- сохранена клавиатурная навигация стандартными ссылками.

## Автоматизация

Добавлены:

- `tools/check_public_404_page.py`;
- `.github/workflows/public-404-page-check.yml`.

Контракт защищает:

- `noindex, nofollow`;
- отсутствие canonical;
- единственный H1 и `main`;
- полезные recovery-ссылки;
- отсутствие формы и внутренних технических терминов.

Общие контракты сайта дополнительно проверяют локальные ресурсы, DOM-связи и HTML/SEO baseline.

## Границы

- CRM UI и `nav_*` не изменяются;
- Supabase не вызывается;
- production-данные не меняются.

## Исправление вложенных адресов — 2026-09-15 (#535)

На `/banner/missing-page-check` Cloud Browser подтвердил: CSS разрешался как
`/banner/assets/public-utility-pages.css` и не загружался; «Все услуги» снова
открывали 404 по `/banner/uslugi.html`. Все локальные href страницы теперь
начинаются с `/`. Checker проверяет разрешение ссылок на трёх глубинах URL.
Браузерный CI проверяет стили, отсутствие горизонтальной прокрутки, Tab и
переход к услугам на 1440/1024/768/390/360 px без внешних запросов.

Служебные Navigator HTML сохранены из-за взаимных callers в
`assets/js/nav-v2/`. Карточка получила `noindex,nofollow`; общий SEO checker
теперь защищает обе оболочки, logo/brand review и UTM tool от индексации,
попадания в sitemap и ссылок из индексируемых HTML. Robots.txt не запрещает
их обход, чтобы поисковик мог прочитать noindex. Это не механизм авторизации.
`portfolio.html` остаётся прежним redirect с canonical на страницу примеров.
