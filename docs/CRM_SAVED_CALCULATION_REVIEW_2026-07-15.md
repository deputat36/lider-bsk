# Сохранённый состав расчёта — 2026-07-15

## Проблема

После объединения типового и нестандартного расчёта интерфейс сохранённых версий продолжал использовать устаревшую подсказку «сначала типовой, затем нестандартный».

Таблица состава также была неудобна на телефоне и не показывала часть важных характеристик новых позиций из PR #315:

- тип позиции;
- режим расчёта;
- диаметр и толщину ПВХ-фигур;
- знак, высоту, цвет и материал букв;
- подробные характеристики ручной позиции;
- источник цены: автоматический или ручной.

## Реализовано

### Единый сценарий

Устаревший текст заменён на актуальный:

- сохранённые версии находятся сверху;
- новый расчёт создаётся ниже в едином конструкторе;
- типовые и нестандартные позиции добавляются в одну смету.

Дублирующая кнопка «Обновить» удалена из каждой карточки. Для всего списка остаётся одна кнопка «Обновить список».

### Карточка сохранённого расчёта

Карточка показывает:

- название;
- статус;
- номер версии;
- сумму клиенту;
- себестоимость;
- прибыль;
- маржу;
- наличие КП или заказа.

Кнопка «Показать состав» использует `aria-expanded` и меняется на «Обновить состав», когда расчёт открыт.

### Состав

В первой ячейке строки объединены:

- порядковый номер;
- название;
- категория;
- тип позиции;
- режим расчёта;
- автоматическая или ручная цена;
- комментарий;
- структурированные характеристики.

Характеристики извлекаются только из уже сохранённого поля `data`.

Новые записи в базу не создаются.

### Mobile 360 и 390 px

При ширине до 720 px таблица превращается в набор карточек.

Каждое значение получает явную подпись:

- позиция;
- единица;
- количество;
- себестоимость за единицу;
- цена клиенту за единицу;
- сумма клиенту;
- маржа.

Горизонтальная прокрутка для просмотра состава не требуется.

## Доступность

Добавлены:

- `aria-label` для каждой строки;
- `aria-expanded` для кнопки открытия;
- `aria-controls` со ссылкой на детали;
- `aria-live` для количества строк;
- понятные тексты «Показать состав», «Обновить состав» и «Скрыть состав».

## Технические границы

Модель `calculation-saved-review-model-v1.js` является чистой browser presentation model.

Модуль просмотра:

- выполняет только существующие SELECT запросы;
- не выполняет INSERT, UPDATE или DELETE;
- не меняет расчётный payload;
- не меняет роли и права;
- не использует service-role credentials;
- не добавляет новые Supabase endpoints.

Supabase не изменяется.

## Ручная проверка

### Desktop

1. Открыть заявку с сохранённым расчётом.
2. Проверить номер версии и финансовые итоги.
3. Нажать «Показать состав».
4. Проверить категории, типы и характеристики ПВХ-фигур.
5. Проверить характеристики букв / цифр.
6. Проверить ручную позицию.
7. Проверить индикатор автоматической и ручной цены.
8. Нажать «Скрыть состав».
9. Проверить единственную кнопку обновления списка.

### Mobile 360 и 390 px

1. Открыть сохранённый расчёт.
2. Проверить отсутствие горизонтальной прокрутки.
3. Проверить, что каждая строка отображается отдельной карточкой.
4. Проверить читаемость всех подписей и характеристик.
5. Проверить доступность кнопок открытия и закрытия состава.

### Keyboard

1. Перейти Tab к «Показать состав».
2. Открыть состав клавишей Enter.
3. Проверить значение `aria-expanded=true`.
4. Перейти к «Скрыть состав» и закрыть его.

### Network

1. Открыть DevTools → Network.
2. Открыть сохранённый состав.
3. Подтвердить только существующий SELECT `leader_lead_calculation_items`.
4. Подтвердить отсутствие INSERT, UPDATE, DELETE и новых Edge-вызовов.
