# Автоматическое уведомление IndexNow

Дата: 2026-07-18.

## Цель

После публикации значимого изменения семи коммерческих страниц GitHub Actions
автоматически сообщает их канонические URL Яндексу через IndexNow. Это сокращает
ожидание до следующего обнаружения изменения обычным обходом и не требует платной
рекламы или ручной отправки каждой страницы.

Официальная документация:

- https://yandex.com/support/webmaster/en/indexing-options/index-now
- https://yandex.com/support/webmaster/en/indexnow/reference
- https://yandex.com/support/webmaster/en/indexnow/key

## Безопасная граница

- корневой verification key является публичным доказательством владения URL, а не
  ключом к GitHub, Supabase или кабинету вебмастера;
- pull request только проверяет payload и ничего не отправляет;
- уведомление выполняется только после push в `main` и успешного source-checker;
- перед POST workflow ждёт, пока файл ключа появится на публичном домене;
- отправляются ровно семь изменённых URL без query parameters;
- HTTP 200 и 202 считаются принятыми согласно документации Яндекса;
- индексация и позиция в выдаче не гарантируются.

## Поддержка

Список URL хранится отдельно в `tools/public-indexnow-urls.txt`. При следующем
значимом изменении коммерческих страниц список и workflow paths следует обновить
вместе. Повторные уведомления без изменения страницы не нужны.
