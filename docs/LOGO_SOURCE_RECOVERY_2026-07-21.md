# Восстановление исходника логотипа РА «Лидер» — 2026-07-21

## Причина

После нескольких попыток преобразовать логотип в компактный чистый SVG фирменное начертание стало визуально отличаться от исходного знака. Дальнейшее ручное перерисовывание без опоры на исходник запрещено.

## Найденный источник

В истории репозитория найден файл из коммита `1f708fcd73ff64afd256128164c0bb15efa06df0` с сообщением `Add exact transparent logo for light background`.

Его исходный Git blob:

`cf9b3f8ffed9b83dd1c327490f1c28245fd839f6`

Blob восстановлен без перекодирования по адресу:

`assets/brand/source/logo-lider-original-20260621.svg`

Файл представляет собой SVG-контейнер с исходным прозрачным PNG. Он хранится только как архивный визуальный источник.

## Запреты

Исходник нельзя:

- подключать в публичные HTML или CSS;
- использовать как рабочий логотип сайта;
- оптимизировать с потерей геометрии;
- автоматически трассировать и сразу публиковать;
- заменять им `assets/brand/logo-lider-header.svg` без визуального согласования.

## Правильный следующий шаг

1. Извлечь исходный PNG из контейнера без ресайза.
2. Сравнить его с текущим `logo-lider-header.svg` на светлом и тёмном фоне.
3. Вручную восстановить контуры знака и фирменного начертания.
4. Проверить варианты 250 × 66, 225 × 60 и 184 × 49 px.
5. Согласовать визуальный результат до подключения на сайт.

## Граница этой работы

- публичный логотип не изменён;
- CSS шапки не изменён;
- production и staging Supabase не изменены;
- файл не участвует в сборке и публикации сайта.
