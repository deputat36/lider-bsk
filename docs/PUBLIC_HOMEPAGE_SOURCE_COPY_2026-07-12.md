# Публичная главная: клиентский текст в исходном HTML

Дата: 2026-07-12.

Scope: public site only.

Related issues: #185, #191.

## Проблема

Главная страница содержала внутренние рабочие формулировки непосредственно в `index.html`:

- заявка попадает в CRM;
- заявка в CRM;
- контроль себестоимости и маржи;
- обработка заказов в CRM;
- передача заявки в рабочую CRM.

`assets/packages-link.js` заменял эти фразы после загрузки JavaScript, но исходный HTML оставался некорректным для поисковых систем, пользователей без JavaScript и ситуаций, когда helper не загрузился.

## Решение

Исходные тексты заменяются точечным guarded patch:

- обращение получает номер и не теряется;
- обращение под контролем;
- клиент получает номер обращения;
- понятный расчёт;
- согласование стоимости, сроков и внешнего вида;
- нейтральное объяснение онлайн-заявки без упоминания внутренних систем.

Patch проверяет, что каждая старая фраза встречается ровно один раз. При изменении структуры страницы он останавливается, а не выполняет неточную массовую замену.

## Постоянная защита

`tools/check_public_homepage_source_copy.py` проверяет:

- title, canonical, Open Graph и JSON-LD;
- обязательные секции главной;
- один H1;
- одну форму заявки;
- одну кнопку мобильного меню;
- порядок `public-lead-form.js?v=4` и `packages-link.js?v=1`;
- наличие клиентских формулировок в исходном HTML;
- отсутствие CRM, себестоимости и маржи в клиентских блоках;
- совпадение исходного текста с runtime helper.

## Почему пока остаётся form JS v4

Главная содержит большой уникальный CSS-блок, фирменный знак, мобильное меню, сценарии, дополнительные ссылки и несколько runtime helpers. Обновление `public-lead-form.js` до `v=5` выполняется отдельным этапом после безопасного сокращения CSS и проверки script order.

## Supabase

Supabase production не изменяется. Активная публичная функция — `leader-public-lead v10`, `verify_jwt=false`.

## Не затронуто

- CRM UI;
- `nav_*` и `nav_v2_*`;
- Edge Functions, migrations, schema, RLS, grants, policies, Auth и данные;
- цены и коммерческие предложения главной.
