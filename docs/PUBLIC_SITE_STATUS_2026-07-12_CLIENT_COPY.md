# Публичный сайт РА «Лидер»: клиентские формулировки главной

Дата: 2026-07-12.

Контур: только публичный сайт `https://www.lider-bsk.ru`.

## Что изменено

В уже подключённом `assets/packages-link.js` добавлен безопасный runtime-слой `clientCopy()` для главной страницы.

Он заменяет внутренние формулировки:

- «заявка сразу попадает в CRM»;
- «Заявка в CRM»;
- «контроль себестоимости и маржи»;
- «Заявка попадёт в CRM РА Лидер»;
- «обрабатывать заказы в CRM»;
- «передает заявку в рабочую CRM».

На клиентские выгоды:

- обращение получает номер и не теряется;
- специалист видит описание задачи;
- до начала работ согласуются вариант, стоимость, сроки и внешний вид;
- клиенту не нужно повторять данные;
- номер обращения можно использовать для быстрой проверки.

## Почему выбран helper-слой

`index.html` содержит крупные минифицированные строки. Точечная запись через GitHub Contents API потребовала бы полной перезаписи файла и создала бы лишний риск повреждения главной страницы.

`assets/packages-link.js` уже подключён после формы и отвечает за безопасные улучшения главной. Изменение ограничено точными CSS-селекторами и повторно выполняется идемпотентно.

## Проверки

Обновлён `tools/check_public_homepage_helper.py`:

- проверяет наличие `clientCopy()`;
- проверяет новые клиентские формулировки;
- запрещает возвращать внутренние CRM/маржинальные тексты в helper;
- сохраняет старые проверки меню, ссылок, мобильного режима и порядка скриптов.

## Ограничение

Исходный HTML пока содержит старые фразы до выполнения JavaScript. Это промежуточный безопасный этап. При последующей нормализации `index.html` формулировки нужно перенести в статический HTML и удалить runtime-подмену.

## Supabase

На предыдущем этапе `leader-public-lead` обновлена до v10 с `verify_jwt=false`. Схема, таблицы, RLS, grants, Auth и данные не изменялись.
