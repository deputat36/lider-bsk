## Следующее действие из расчёта в КП

Обновление 2026-07-17:

- свободный сохранённый расчёт показывает главное действие `Сформировать КП`;
- переход из карточки подставляет точную версию расчёта и прокручивает к форме КП без сетевого запроса;
- единственный доступный расчёт выбирается автоматически, при нескольких версиях сохраняется явный выбор;
- расчёты с существующим КП, заказом или неположительной суммой не предлагаются повторно;
- существующее КП дополнительно распознаётся по `calculation_id`, даже если обратная ссылка расчёта не обновилась после прежней частичной ошибки;
- при ошибке загрузки списка КП новое создание fail closed;
- чтение и создание КП fail closed через canonical permissions `offers.read` и `offers.write`;
- исторический multi-write создания КП не изменён и остаётся кандидатом на server command;
- Supabase production/staging, DDL/DML, RLS, Auth, Storage, Edge Functions и реальные данные не менялись.
