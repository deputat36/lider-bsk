# Этажи • СМС Визитка — Android v0.5.2

Версия: 0.5.2 (versionCode 8). Минимум: Android 10 (API 29).

## Исправлено

- Повторная проверка выбранных номеров непосредственно перед созданием очереди: стоп-лист, мобильность и ограничения по последней подготовке SMS
- Уже выделенные контакты исключаются из выбора при включении более строгих фильтров
- Выделение контактов, поиск и переключатели фильтров восстанавливаются после пересоздания экрана
- Исправлен учёт вручную подготовленных SMS: история записывается только после успешного запуска системного SMS-клиента; это не подтверждение фактической отправки
- Для очереди SMS-клиент открывается напрямую; если открытие отклонено, состояние очереди возвращается к прежнему
- Зарубежные номера разрешены только с явным префиксом +код страны; обычные российские форматы +7/8/9 поддерживаются
- Добавлена проверка неподдерживаемых переменных в шаблонах
- Обработаны системные отступы Android 15+ (edge-to-edge)
- Настройки и выбранная вкладка восстанавливаются при смене ориентации
- Ограничение одной кампании — до 1000 адресатов, чтобы уменьшить риск перегрузки бюджетных устройств
- Перед рассылкой добавлено напоминание проверить согласие получателей при рекламных сообщениях

## Проверки

GitHub Actions выполняет сборку debug/release, Android Lint и JUnit-тесты. Проверки v0.5.2 прошли успешно: 0 ошибок Lint, 10 предупреждений (локализация строк и ресурсы).

## Что остаётся

- На некоторых устройствах SMS-баннер после вызова может ограничиваться производителем или настройками пользователя
- Не гарантируется корректный сценарий двух одновременных вызовов / call waiting на разных SIM: нужен отдельный журнал событий звонков и испытания на физических телефонах
- Большая очередь всё ещё сохраняется в JSON/AtomicFile, а не в Room/SQLite — для очень больших кампаний нужна оптимизация
- История «подготовлено» не подтверждает отправку или доставку SMS
- Debug APK предназначен для тестов; для массовой установки требуется постоянная безопасная release-подпись

Возможности и данные локальные, скрытой массовой отправки SMS нет.
