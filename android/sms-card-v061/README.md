# Этажи • СМС Визитка — v0.6.1 (Android 10+)

## Исправление SMS-номера получателя

Исправлена ошибка v0.6.0: внутренний формат российских номеров `79991234567` передавался в системное приложение сообщений без международного префикса.

Теперь функция `PhoneNormalizer.toSmsRecipient()` преобразует любой поддерживаемый российский формат `8 999...`, `999...`, `7999...`, `+7 999...` в **`+79991234567`**. Международные номера с явным знаком `+` сохраняют его. Неоднозначные/некорректные номера блокируются.

Исправлены **оба** сценария формирования `ACTION_SENDTO`: обычная/после звонка через `SmsComposeActivity` и массовая очередь через `BulkCampaignActivity`.

**Важно:** для хранения, дедупликации, истории и стоп-листа сохранён прежний формат `7XXXXXXXXXX`. Миграция SQLite и данные не меняются, `versionCode = 10`, `versionName = 0.6.1`.

При подготовке SMS используется URI вида `smsto:+79991234567` (literal `+`), а фактическое отправление остаётся ручным в системном SMS-приложении.

Добавлены JUnit-регрессионные проверки для `+7`, `8`, `9`, `7`, зарубежных и неверных номеров. Они запускаются вместе с прежними тестами, Lint и сборкой APK в GitHub Actions.

## Установка и подпись

Приложение поддерживает Android 10+. Debug APK предназначен для тестирования. Постоянная release-подпись пока не настроена; debug APK может не установиться поверх предыдущей debug-сборки с другим ключом. **Не удаляйте v0.6.0 до сохранения важных данных:** JSON-экспорт не включает активную кампанию/стоп-лист.

## Проверка после установки

1. Ручное SMS на тестовый российский номер — получатель должен быть `+7...`.
2. Входящий и исходящий звонок → уведомление → SMS — номер `+7...`.
3. Рассылка на 2–3 собственных номера — номер каждого адресата начинается с `+7`.
4. При наличии зарубежного тестового номера он должен оставаться в формате `+код`.
