# Этажи • СМС Визитка — Android v0.4.0

Небольшое Android-приложение для специалистов по недвижимости: после звонка предлагает открыть готовую SMS-визитку клиента, а также позволяет быстро подготовить сообщение вручную.

## Основной сценарий

1. Специалист завершает входящий или исходящий звонок.
2. Android показывает уведомление «Отправить визитку?». При правильно настроенном канале оно появляется как всплывающий heads-up баннер.
3. Одно нажатие открывает штатное SMS-приложение с уже заполненными номером и текстом.
4. Само приложение SMS скрытно не отправляет и не запрашивает `SEND_SMS`.

## Возможности v0.4.0

- 5 полностью редактируемых шаблонов SMS;
- имя клиента никогда не берётся автоматически из названия контакта;
- предпросмотр и системный расчёт количества частей SMS;
- история именно подготовленных, а не подтверждённо отправленных SMS;
- защита от повторной подготовки: без ограничения / 1 / 7 / 30 / 90 дней;
- предупреждение перед ручной повторной подготовкой с возможностью продолжить;
- тест шаблона на собственный номер без записи в историю;
- диагностика разрешений, роли скрининга, канала уведомлений и фоновых ограничений;
- тестовое всплывающее уведомление;
- быстрый переход в системные настройки уведомлений, батареи и приложения;
- подсказки для Samsung, Xiaomi/Redmi/POCO, vivo/iQOO, OPPO/realme/OnePlus, Huawei/Honor и других оболочек;
- экспорт/импорт профиля, настроек автоматизации и SMS-шаблонов в JSON;
- история номеров в экспорт не включается;
- все данные хранятся локально.

## Совместимость

Android 10+ (`minSdk 29`). Основная логика построена на официальном `CallScreeningService` и роли `ROLE_CALL_SCREENING`, а не на приватных API конкретного производителя.

Разные оболочки Android по-разному ограничивают фоновые процессы и всплывающие уведомления. Поэтому v0.4.0 содержит встроенную диагностику и тест уведомления.

## Разрешения

- `READ_PHONE_STATE` — определить завершение звонка;
- `READ_CONTACTS` — нужен системе для CallScreeningService и сохранённых номеров;
- `POST_NOTIFICATIONS` — Android 13+;
- роль `ROLE_CALL_SCREENING` — номер и направление звонка через официальный Android API.

`READ_CALL_LOG` и `SEND_SMS` не запрашиваются.
