# Этажи • СМС Визитка — Android v0.5.1

Стабилизационный релиз приложения для специалистов по недвижимости. Android 10+.

## Что исправлено после аудита v0.5.0

- очередь массовой рассылки хранится через `AtomicFile`: внезапное завершение процесса не должно оставлять частично записанный JSON;
- добавлен отдельный реестр последних обработанных номеров до 5000 записей — защита от повторов больше не зависит от экранной истории на 100 строк;
- в выборе контактов по умолчанию показываются мобильные номера;
- можно исключить контакты, которым SMS уже подготавливалось в настроенный период 1/7/30/90 дней;
- добавлен локальный стоп-лист с добавлением прямо из очереди и возможностью снять блокировку;
- номера с post-dial/extension не склеиваются с добавочными цифрами;
- зависшая сессия звонка старше 12 часов автоматически отбрасывается;
- уведомления после звонка используют отдельные ID: несколько звонков больше не обязаны перезаписывать одно уведомление;
- телефон клиента скрывается на lock screen: канал и уведомление имеют private visibility;
- локальная клиентская информация исключена из Android cloud backup и device-to-device transfer; для переноса настроек используйте встроенный JSON-экспорт;
- диагностика фоновой работы использует `ActivityManager.isBackgroundRestricted()`, а обычная оптимизация батареи больше не считается ошибкой сама по себе;
- возврат из системных настроек не перестраивает экран и не стирает несохранённые поля;
- элементы управления лучше выдерживают крупный системный шрифт и маленькие экраны;
- ошибки сохранения очереди больше не игнорируются молча.

## Автоматические проверки

CI выполняет:
- `:app:testDebugUnitTest`;
- `:app:lintDebug`;
- `:app:assembleDebug`;
- `:app:assembleRelease`.

Добавлены регрессионные тесты нормализации российских номеров/добавочных и TTL звонковой сессии.

## Массовые рассылки

Отправка остаётся безопасной: приложение не получает `SEND_SMS` и не отправляет сообщения скрытно. Каждый адресат обрабатывается отдельно через стандартное SMS-приложение.

Статус «Подготовлено» не означает подтверждённую доставку — Android не возвращает стороннему приложению факт нажатия «Отправить» в системном SMS-клиенте.

## Данные

Профиль, шаблоны, история, стоп-лист и активная очередь хранятся локально. Клиентские данные исключены из системного backup/transfer. Профиль и шаблоны можно переносить вручную через JSON экспорт/импорт; история контактов и кампании в этот файл не входят.

## Подпись релиза

Debug APK подходит для тестирования. Release APK в CI остаётся unsigned до подключения постоянного приватного keystore через защищённые CI secrets. Приватный ключ нельзя хранить в репозитории.
