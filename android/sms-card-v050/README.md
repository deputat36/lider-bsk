# Этажи • СМС Визитка — Android v0.5.0

Локальное Android-приложение для специалистов по недвижимости: после звонка предлагает открыть готовую SMS-визитку, позволяет отправлять визитку вручную и вести очереди индивидуальных SMS по контактам телефона.

## Основные функции

- предложение отправить SMS-визитку после входящего / исходящего / пропущенного звонка;
- полностью редактируемые шаблоны SMS и переменные профиля;
- ручная быстрая подготовка SMS;
- история подготовленных SMS;
- диагностика разрешений, роли скрининга, уведомлений и фоновых ограничений;
- экспорт / импорт профиля, автоматизации и шаблонов;
- Android 10+.

## Рассылки v0.5.0

Раздел `Рассылки` реализует безопасную очередь сообщений по телефонной книге без скрытой автоматической отправки:

1. Выбрать шаблон и при необходимости полностью изменить текст кампании.
2. Найти контакты по имени или номеру.
3. Выбрать отдельных получателей или всех найденных.
4. Дубли одинаковых телефонных номеров автоматически удаляются.
5. Создать очередь.
6. Для каждого адресата приложение открывает штатное SMS-приложение с готовым номером и текстом.
7. После возврата пользователь вручную нажимает `Готово — следующий` или `Пропустить`.
8. Рассылку можно поставить на паузу и продолжить позже с того же контакта.
9. Завершённые и отменённые кампании сохраняются в истории с количеством подготовленных и пропущенных адресатов.

### Важные ограничения

- приложение не получает `SEND_SMS` и не отправляет сообщения скрытно;
- факт реальной отправки и доставки SMS системное приложение сообщений нам не сообщает;
- поэтому в интерфейсе используется термин `Подготовлено`, а не `Доставлено`;
- имя из телефонной книги используется только для выбора адресата и не подставляется автоматически в текст сообщения;
- `{client_name}` при массовой рассылке остаётся пустым, а строка с пустой переменной удаляется;
- контакты и кампании хранятся только локально на смартфоне.

## Совместимость

- `minSdk 29` — Android 10;
- `targetSdk 37`;
- Java 17;
- официальные Android API: `CallScreeningService`, `ContactsContract`, `ACTION_SENDTO`;
- без `READ_CALL_LOG` и `SEND_SMS`.

Версия: `0.5.0`, `versionCode 6`.
